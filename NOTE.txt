KONTEKS GLOBAL (WAJIB DIGUNAKAN UNTUK SEMUA OUTPUT):
Saya ingin membangun FRONTEND Web Application dengan laravel untuk WhatsApp Gateway SaaS Multi-Device.
Frontend ini HANYA sebagai CLIENT yang mengonsumsi REST API + Socket.IO dari backend Node.js WhatsApp Gateway.

==================================================
BATASAN & RUANG LINGKUP:

* HANYA frontend (TIDAK membuat backend)
* TIDAK membuat logika WhatsApp
* Semua data berasal dari API backend Node.js
* Frontend bersifat production-ready, modular, dan scalable

==================================================
TEKNOLOGI FRONTEND WAJIB:

* Laravel (Blade)
* Bootstrap 5
* Ajax Jquery
* Socket.IO client
* Chart.js (untuk statistik)
* SweetAlert / Toast notification
* Datatable ajax serverside

(JIKA PERLU AUTH):

* API Key / Token dari backend
* Simpan token dengan aman (session / local storage sesuai best practice)
